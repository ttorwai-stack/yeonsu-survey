연수 설문 시스템 설치 매뉴얼

내 구글 계정과 GitHub 계정만으로 나만의 연수 설문 시스템을 만드는 방법이에요. 처음이어도 30분 정도면 끝나요. 비용은 들지 않아요.

0. 먼저 이해하기

연수생 → ① 화면(GitHub Pages) → ② 서버(Apps Script) → ③ 저장소(구글 시트·드라이브)

부품하는 일누구 계정?
① 화면
(index.html, admin.html)		연수생이 보는 설문 화면, 내가 보는 관리·결과 화면내 GitHub
② 서버
(Code.gs)		응답을 받아 시트에 저장하고, 비밀번호를 확인하고, 설문을 만들어 줌내 구글
③ 저장소관리용 시트(설문 목록)와, 설문마다 자동으로 만들어지는 응답 시트내 구글 드라이브
내 설문과 응답은 내 구글 드라이브에만 저장돼요. 이 시스템을 알려준 사람은 내 응답을 볼 수 없어요.

준비물

  • 구글 계정 (지메일)
  • GitHub 계정 (github.com/signup에서 무료 가입)
  • 받은 파일: index.html, admin.html, Code.gs
  • 컴퓨터 (설치는 컴퓨터로 하는 게 편해요. 설치 후 관리·결과 보기는 폰에서도 돼요)

1GitHub에 화면 올리기

  1. GitHub에 로그인한 뒤 오른쪽 위 + → New repository를 눌러요.
  2. Repository name에 영어 이름을 적어요. 예: my-survey
  3. Public을 선택하고 Create repository를 눌러요.
  4. 만들어진 화면에서 uploading an existing file 링크를 눌러요.
  5. index.html과 admin.html 두 파일을 끌어다 놓고, 아래쪽 Commit changes를 눌러요.
  6. 위쪽 Settings → 왼쪽 Pages로 가요.
  7. Source는 Deploy from a branch, Branch는 main / (root)로 고르고 Save를 눌러요.
  8. 1~2분 뒤 같은 화면 위쪽에 내 사이트 주소가 나와요. 이걸 적어 두세요. 
    https://내GitHub아이디.github.io/my-survey/
Public(공개)이어야 해요. 무료 계정은 공개 저장소만 Pages를 쓸 수 있어요. 올리는 파일은 화면 코드뿐이고 설문 응답이나 비밀번호는 들어 있지 않아서 괜찮아요.

2구글 시트에 서버 코드 넣기

  1. sheets.new로 새 스프레드시트를 만들고 이름을 연수 설문 DB로 바꿔요.
  2. 위 메뉴 확장 프로그램 → Apps Script를 눌러요. 새 탭에 편집기가 열려요.
  3. 편집기 가운데 코드(function myFunction() {...})를 모두 지우고, 받은 Code.gs 내용을 전체 복사해서 붙여넣어요.
  4. 코드 위쪽에서 PAGES_BASE가 있는 줄을 찾아 1단계에서 적어 둔 주소로 바꿔요. 끝의 /까지 넣어요. 
    var PAGES_BASE = 'https://내GitHub아이디.github.io/my-survey/';
  5. Ctrl+S(맥은 ⌘+S)로 저장해요. 프로젝트 이름을 물으면 아무거나 적어도 돼요.

3초기 설정 (처음 한 번)

  1. 구글 시트 탭으로 돌아가 새로고침(F5)을 해요. 몇 초 뒤 메뉴에 설문 도구가 생겨요.
  2. 설문 도구 → ① 초기 설정을 눌러요.
  3. 권한 승인 창이 뜨면 내 계정을 고르고 허용해요.
    "확인되지 않은 앱" 경고가 나와요. 내가 방금 만든 코드라서 정상이에요. 고급 → (안전하지 않음)으로 이동 → 허용 순서로 누르세요.
  4. 끝나면 다시 설문 도구 → ① 초기 설정을 한 번 더 눌러요. 이번에는 관리자 비밀번호를 묻는데, 설문 관리 화면에 들어갈 때 쓸 비밀번호를 정해서 입력하세요.
  5. "초기 설정 완료" 창이 뜨면 성공이에요. 내 드라이브에 연수 설문 폴더가 생겨요.
비밀번호는 너무 쉽게 정하지 마세요. 연수생에게는 알려주지 않아요. 잊어버리면 설문 도구 → 관리자 비밀번호 변경으로 다시 정할 수 있어요.

4웹앱으로 배포하기

  1. Apps Script 편집기 오른쪽 위 배포 → 새 배포를 눌러요.
  2. 왼쪽 톱니바퀴(유형 선택) → 웹 앱을 골라요.
  3. 다음처럼 설정하고 배포를 눌러요.
    실행 사용자나
    액세스 권한이 있는 사용자모든 사용자
  4. 권한을 다시 물으면 3단계처럼 허용해요.
  5. "새 배포 만들기" 창에 웹 앱 URL이 나오지만 복사하지 않아도 돼요. 다음 단계에서 주소를 따로 받아요.
"모든 사용자"가 맞아요. 연수생이 구글 로그인 없이 응답해야 해서 그래요. 관리 기능은 비밀번호가 없으면 쓸 수 없어요.

5내 관리자 페이지 열기

  1. 구글 시트 탭에서 설문 도구 → 웹앱 주소 보기를 눌러요.
  2. "관리자 페이지" 아래에 나오는 주소를 복사해서 브라우저에 붙여넣어요. 이런 모양이에요. 
    https://내GitHub아이디.github.io/my-survey/admin.html?api=AKfycb…
  3. 3단계에서 정한 비밀번호로 들어가요.
  4. 이 주소를 즐겨찾기해 두세요. 폰에도 보내 두면 편해요.
주소 뒤의 ?api=AKfycb…가 "내 서버가 어디인지" 알려주는 부분이에요. 지우지 마세요. 한 번 들어오면 그 기기가 기억해 줘요.

6첫 설문 만들고 보내기

  1. 관리자 페이지에서 새 설문을 눌러 틀(사후설문 / 사전설문 / 빈 설문)을 골라요.
  2. 제목, 과정명, 기수, 안내 문구, 문항을 내 연수에 맞게 고치고 저장해요.
  3. 자동 마감 예약: 설문 목록(또는 설문 화면 위쪽)의 예약 마감을 누르고 2026-11-01 23:59처럼 한국 시간으로 적으면 그 시각에 응답 접수가 자동으로 멈춰요. 비우고 확인하면 예약이 해제돼요. 마감된 설문을 다시 열기하면 지난 예약은 지워져요.
  4. 몇 점 척도로 할지: 척도 묶음의 척도 칸에 쉼표로 3~7개를 적으면 그 개수가 점수 개수가 돼요. 5개면 5점 척도, 4개면 4점 척도예요. 이미 응답이 있는 설문의 개수를 바꾸면 이전 응답과 점수 기준이 달라지니 새 설문에서 정하세요.
  5. 설정 텍스트로 한 번에 만들기: 받은 설정 텍스트({로 시작, 예: 함께 들어 있는 samples/현업활용도-샘플.json)가 있으면 새 설문 만들기 → 설정 붙여넣기에 붙여넣고 이 설정으로 만들기를 누르면 문항까지 한 번에 만들어져요. 내 설문의 설정 화면에서 설정 복사를 누르면 같은 형태의 텍스트를 다른 설문·다른 관리자에게 줄 수 있어요.
  6. 설문 목록의 링크 복사를 눌러 연수생에게 보내요. (문자, 메신저, QR 모두 가능)
  7. 꼭 먼저 직접 응답해 보세요. 폰으로 응답한 뒤 결과 화면에 잘 들어왔는지 확인하면 안심이에요.
  8. 응답 수집이 끝나면 마감하기를 눌러요. 필요하면 다시 열기도 돼요.

데이터는 어디에 쌓이나요?

  • 드라이브 연수 설문 폴더에 설문마다 시트가 하나씩 만들어져요.
  • 응답자 탭: 한 줄에 응답자 1명. 점수 탭: 한 줄에 점수 1개(피벗 표나 통계용). 수신 탭: 접수 대기함이라 건드리지 마세요.
  • 설정 탭은 설문 설정 원본이라 직접 고치지 마세요. 항상 관리자 페이지에서 고쳐요.

7. 선택 사항

연수생 링크를 짧게 만들기

기본 링크에는 ?api=…가 붙어서 길어요. 짧게 하려면 GitHub의 index.html, admin.html 두 파일에서 DEFAULT_API_ID가 있는 줄을 찾아 내 배포 ID(AKfycb…)를 넣으세요. 파일 화면의 연필 아이콘으로 고치고 Commit changes를 누르면 돼요.

var DEFAULT_API_ID = 'AKfycb여기에내배포ID';

배포 ID는 5단계 관리자 주소에서 api= 뒤의 글자예요.

코드를 고친 뒤 다시 배포하기

Code.gs를 고쳤다면 Apps Script 편집기에서 배포 → 배포 관리 → 연필 아이콘 → 버전 새 버전 → 배포를 눌러요. 새 배포를 만들지 말고 기존 배포를 편집해야 주소(배포 ID)가 그대로 유지돼요.

화면 파일 업데이트 받기

새 버전의 index.html, admin.html을 받으면 GitHub 저장소에서 Add file → Upload files로 같은 이름으로 올려 덮어쓰세요. 단, 7번의 DEFAULT_API_ID를 고쳐 뒀다면 새 파일에도 다시 넣어야 해요.

8. 문제가 생겼을 때

관리자 페이지에서 "서버가 연결되지 않았어요"가 떠요

주소 뒤에 ?api=…가 빠졌어요. 시트의 설문 도구 → 웹앱 주소 보기에서 나온 주소로 다시 들어가세요.

"초기 설정이 필요해요"가 떠요

3단계를 안 했거나, 다른 시트에 붙인 코드를 배포했어요. 설문 DB 시트에서 설문 도구 → ① 초기 설정을 실행하세요.

"비밀번호가 맞지 않아요"가 떠요

시트 메뉴 설문 도구 → 관리자 비밀번호 변경으로 새로 정하세요.

"웹앱 주소 보기"에서 PAGES_BASE를 바꾸라고 해요

2단계 4번을 빠뜨렸어요. 코드 위쪽 PAGES_BASE를 내 GitHub Pages 주소로 바꾸고 저장하세요. 주소는 https://아이디.github.io/저장소이름/ 모양이어야 하고, 끝에 /가 있어야 해요.

GitHub 주소로 들어가면 404가 떠요

Pages를 켠 직후에는 1~2분 걸려요. 계속 안 되면 Settings → Pages에서 Branch가 main인지, 저장소가 Public인지 확인하세요. 주소 끝에 admin.html을 붙였는지도 보세요.

연수생이 제출했는데 "서버가 바빠요" 또는 오류가 나요

배포의 액세스 권한이 "모든 사용자"인지 확인하세요(배포 관리에서 볼 수 있어요). 구글이 일시적으로 혼잡할 때는 화면이 자동으로 다시 시도해요. 수십 명이 동시에 낼 때도 접수 대기함 방식이라 응답이 사라지지 않아요.

결과 화면에 응답이 안 보여요

결과 화면을 새로고침하세요. 접수 대기함(수신 탭)에 있는 응답도 결과에 합쳐서 보여줘요. 그래도 없으면 연수생이 다른 설문 링크로 응답한 건 아닌지 확인하세요.

구글 계정이 바뀌면 어떻게 하나요?

설문 DB 시트와 연수 설문 폴더를 새 계정으로 옮기는 건 복잡해요. 처음부터 오래 쓸 계정(개인 지메일 권장)으로 만드세요.

이 시스템을 쓰는 사람을 늘리고 싶어요

관리자가 여러 명이면 각자 이 매뉴얼대로 자기 시트·자기 서버를 만들면 돼요. 같은 GitHub 화면을 같이 써도 되고, 각자 따로 올려도 돼요. 링크의 api=로 각자의 서버를 구분해요.

9. 개인정보와 안전

  • 설문에는 이름·연락처 같은 식별 정보를 묻지 않는 것을 권장해요. 통계용 기본 정보(직급, 경력 등)만 쓰면 부담이 적어요.
  • 응답 시트는 내 드라이브에 있고 나만 볼 수 있어요. 다른 사람과 공유할 때는 필요한 시트만 공유하세요.
  • 관리자 비밀번호는 쉽게 추측되지 않게 정하고, 연수생과 공유하지 마세요.
  • GitHub 저장소는 공개이므로 화면 파일 외에 개인정보 파일을 올리지 마세요.

10. 사용 조건

이 시스템은 자유롭게 설치해서 쓸 수 있어요. 대신 아래 제작 표시는 화면 하단에서 지우거나 바꾸지 말고 그대로 유지해 주세요. index.html, admin.html, Code.gs에 들어 있어요.
